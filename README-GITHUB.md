# Surxondaryo Invest Hub

Готовый React/TanStack Start проект государственного инвестиционного портала.

## GitHub
Загрузите все файлы из архива в корень репозитория с заменой существующих файлов.

## Vercel
- Framework preset: Vite / Other
- Build command: `npm run build`
- Output определяется конфигурацией TanStack Start автоматически.

## Локальный запуск
```bash
npm install
npm run dev
```

## Реальные данные
Текущая версия содержит рабочий публичный интерфейс, фильтры, формы и интерактивную схему. Для общего редактирования данных несколькими администраторами и сохранения обращений нужен серверный backend (например Supabase). Пароли администратора нельзя безопасно хранить в открытом GitHub frontend-коде.

## Yandex Maps
На странице контактов подключена Yandex map widget. Для полноценного GIS-редактора нужен Yandex Maps JavaScript API key и серверное хранилище объектов.
