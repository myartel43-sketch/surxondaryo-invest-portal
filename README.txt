PUBLIC AI + INSTANT TRANSLATION

Что изменено

1. Публичный AI-помощник:
- всегда виден справа снизу на всех страницах;
- открывается поверх сайта;
- работает на компьютере и телефоне;
- поддерживает 5 языков;
- использует существующую Supabase Edge Function admin-ai;
- не получает административную сессию и не имеет доступа к админ-панели.

2. Перевод:
- выбранный язык читается из localStorage до первого отображения React;
- перевод запускается через useLayoutEffect до отрисовки кадра;
- переводчик заменяет фразы внутри длинного текста, а не только при полном совпадении;
- узбекская латиница формируется без задержки;
- при переключении языка страница кратко скрывается, чтобы не показывать смешанные языки.

Установка

1. Загрузите папку src в GitHub с заменой.
2. Дополнительно импортируйте файл src/instant-language.css в главный CSS или src/routes/__root.tsx:
   import "@/instant-language.css";

3. Commit:
   Add public AI and instant site translation

4. Дождитесь Vercel Ready.
5. Нажмите Ctrl + Shift + R.

Важно для публичного AI

Supabase Edge Function admin-ai должна принимать запрос с publishable/anon key.
Если функция возвращает 401:
Supabase → Edge Functions → admin-ai → Settings
Verify JWT with legacy secret можно оставить включённым, если anon key принимается.
Если 401 остаётся, выключите Verify JWT и сохраните изменения.
Сам код функции должен ограничивать публичного помощника только общими вопросами сайта.
