INTERACTIVE ADMIN MAP

1. Upload all src files to GitHub with replacement.
2. Run supabase/interactive-map-editor.sql in Supabase SQL Editor.
3. Wait for Vercel status Ready.
4. Admin editor:
   https://surxondaryo-invest-portal-six.vercel.app/admin/map
5. Public read-only map:
   https://surxondaryo-invest-portal-six.vercel.app/map

The editor supports:
- OpenStreetMap street layer
- Esri satellite layer
- markers
- polylines
- polygons
- rectangles
- edit and delete
- object photo upload
